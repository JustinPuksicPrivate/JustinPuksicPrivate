## 🎮 Core Projects

### Huntdown – Supernatural Text RPG

Unofficial **Supernatural** text-based online RPG built as a browser game.

- **huntdown_beta** – Core game: **Laravel**, **PHP 8**, **MySQL**  
  Topics: `laravel-framework`, `browsergame`, `php8`  
- **huntdown_bot** – Standalone **Laracord** bot (Laravel Zero + DiscordPHP)  
  Handles game events, commands, and community automation as a separate long-running process.  
- **huntdown_android** – Android launcher via **Trusted Web Activity (TWA)**  
  Wraps [huntdown-bg.de](https://huntdown-bg.de); Chrome renders the live site full-screen behind a launcher icon.  
- **Huntdown_Android_native** – Kotlin experiments around the Android UX / launcher experience.

> A fan project inspired by the *Supernatural* universe, focused on lore-accurate characters and choices.
